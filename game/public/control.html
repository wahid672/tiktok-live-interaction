Petunjuk Memasukkan ke OBS Studio

  1. Buka OBS Studio.
  2. Di panel Sources (Sumber), klik tombol `+` ➔ pilih Browser.
  3. Masukkan URL: http://localhost:3000
  4. Atur Resolusi:
    • Width: 1080 (atau 600)
    • Height: 1920 (atau 900)
  5. Centang opsi "Control audio via OBS" jika ingin audio game diatur melalui mixer OBS.
  6. Klik OK dan posisikan game di layar live streaming Anda!
